# Change Log

All notable changes to the "motion-studio" extension will be documented in this file.

## [1.0.0] - 2026-04-01

### Initial Release

- TCP/IP and Serial port device communication
- Interactive command-line interface with history and tab completion
- Automatic device discovery via Bonjour (TCP/IP)
- Binary protocol serialization and deserialization
- Status bar connection indicator
- Support for Motion Framework protocol commands
